 Contrats API & Résilience Système

                            
    
                                
  •  Spécification OpenAPI formelle (`@minfo/api-contract`) servant de source de vérité unique pour les 4 applications.
    • 
                                
  •  Authentification unifiée et sécurisée par JWT, échange de tokens marchands Shopify et synchronisation en temps réel via WebSockets.
    • 
                                
  •  Déploiement automatisé avec reverse proxy Nginx, services systemd gunicorn et cache Redis distribué.
    • 
                            

                        

                        

                            
 Packages Partagés & Code Sharing

                            
    
                                
  •  @minfo/studio-ui : Bibliothèque de composants React partagés entre l'application Web et le Dashboard Shopify.
    • 
                                
  •  @minfo/minfo_sdk : Moteur Dart propriétaire de décodage des fréquences audio (AudioQR).
    • 
                                
  •  Support complet de 17 langues avec gestion dynamique des directions d'écriture LTR et RTL.
