                 المشروع الهندسي الرائد
                
Minfo : منظومة التجارة الذكية عبر الصوت والباركود (AudioQR)

                

                    تحويل المنتجات والبطاقات والأحداث الفيزيائية إلى تجارب رقمية تفاعلية وفورية عبر الرموز التفاعلية والبصمات الصوتية المسجلة.
                

            


            

                

                    

                        

                             معمارية Monorepo متعددة المنصات
                        

                        
منظومة Minfo المتكاملة

                        

                            تصميم وبناء نظام متكامل يجمع بين خوادم Django REST الفائقة، وتطبيق الويب React 19، وتطبيق الجوال Flutter المجهز بمحرك AudioQR، وتطبيق شوبيفاي المدمج (Shopify Polaris).
                        

                    

                    
                


                

                    
                    

                        

                            

                            
1. خادم Django REST

                            github.com/codelab-bj/minfo-v2-backend
                            
واجهة برمجية كاملة (أكثر من 30 وحدة: الحملات، الروابط الذكية، مصمم الاستوديو، أحداث حية، ومحفظة Apple/Google).

                            

                                Django 5
                                PostgreSQL
                                Redis
                                VPS / Nginx
                            

                        


                        

                            

                            
2. تطبيق الويب React 19

                            github.com/codelab-bj/minfo-v2-web
                            
لوحة تحكم تفاعلية لصناع الحملات مع محرر سحب وإفلات، ومحرر نصوص متقدم TipTap، وتتبع PostHog.

                            

                                React 19
                                TypeScript
                                Vite
                                17 لغة
                            

                        


                        

                            

                            
3. تطبيق الجوال Flutter

                            github.com/codelab-bj/minfo-v2-flutter
                            
تطبيق هجين فائق السرعة للتعرف المباشر على التوقيعات الصوتية والرموز البصرية في الوقت الفعلي.

                            

                                Flutter 3.x
                                Dart
                                WebRTC
                                AudioQR SDK
                            

                        


                        

                            

                            
4. تطبيق شوبيفاي المدمج

                            github.com/rstorti/minfo-shopify-dash
                            
تطبيق مدمج داخل لوحة تحكم تجار شوبيفاي لإنشاء حملات تفاعلية وربط المنتجات بصوتيات وباركود Minfo.

                            

                                Shopify Polaris
                                App Bridge
                                React 18
                            

                        

                    


                    
                    

                        

                            
 معايير API والاعتمادية

                            
    
                                
  •  مواصفة OpenAPI رسمية (`@minfo/api-contract`) مرجعية مركزية للعملاء الأربعة.
    • 
                                
  •  نظام مصادقة متعدد المستأجرين مع تبادل آمن لرموز شوبيفاي وتزامن فوري عبر WebSockets.
    • 
                                
  •  نشر مؤتمت على خوادم Ubuntu مع Nginx كوكيل عكسي وخوادم Gunicorn وذاكرة تخزين مؤقت Redis.
    • 
                            

                        

                        

                            
 الحزم المشتركة وتعدد المنصات

    • 
                                
  •  @minfo/minfo_sdk: محرك فك ترميز الإشارات الصوتية بلغة Dart.
    • 
                                
  •  دعم كامل لـ 17 لغة عالمية مع مراعاة كاملة للاتجاهين LTR و RTL للغة العربية.
